Project 2 — Student Management System
Цель: написать консольную программу управления студентами в одном файле main.py.
Используются списки, функции, циклы, условия, проверка ввода и исключения. Словари,
классы, базы данных и дополнительные модули не требуются.

4. Примеры функций
Эти функции показывают принцип работы с двумя списками. Остальные функции проекта
нужно реализовать самостоятельно.
def add_student(students, grades, name, grade):
 if name in students:
 raise ValueError("Студент уже существует")
 if not 0 <= grade <= 100:
 raise ValueError("Оценка должна быть от 0 до 100")
 students.append(name)
 grades.append(grade)

def show_students(students, grades):
 for i in range(len(students)):
 print(students[i], "-", grades[i])
def find_student(students, grades, name):
 if name not in students:
 raise ValueError("Студент не найден")
 index = students.index(name)
 print(name, "-", grades[index])
5. Задание: собрать приложение
• Создать main.py и два пустых списка: students и grades.
• Реализовать add_student(), show_students() и find_student().
• Написать update_grade() — изменить оценку по имени.
• Написать delete_student() — удалить имя и оценку по одному индексу.
• Написать average_grade() — вычислить средний балл (учесть пустой список).
• Создать меню в цикле while True; команда 0 завершает программу.
• Для ввода оценки использовать int() и try/except.
• Проверять диапазон оценок 0–100 и не допускать повторяющихся имён.
